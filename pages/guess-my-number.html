❓ Guess My Number! - Guide

🌟 About This Project

Guess My Number is a classic interactive game that tests your intuition and logical thinking. The computer selects a random number between 1 and 20, and your challenge is to discover it in as few attempts as possible!

🎮 How to Play

  • 🔢 Start: Enter a number between 1 and 20 in the input field
  • ✔️ Check: Click the "Check!" button or press Enter to submit your guess
  • 💡 Hints: The game will tell you if your guess is "Too High!" or "Too Low!"
  • 📊 Score: You start with 20 points. Each wrong guess reduces your score by 1
  • 🏆 Win: Guess the correct number to win and save your score as highscore!
  • 🔄 Play Again: Click the "Again!" button to restart the game anytime

💡 Tips for Success

  • Use binary search strategy: start with 10, then go higher or lower based on hints
  • Pay attention to the feedback messages
  • Try to beat your highscore with fewer attempts!

⚙️ Technical Features

  • Built with vanilla JavaScript (no frameworks)
  • Responsive design for all devices
  • Accessible with keyboard navigation
  • Clean UI with visual feedback
