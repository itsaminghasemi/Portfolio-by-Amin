📚 Family Knowledge Exam - Guide

🌟 About This Project

This is an interactive exam platform designed for practicing Family Knowledge and Population studies. It features a clean, modern interface with RTL support for Persian language, allowing students to test their knowledge with multiple-choice questions.

🎮 How to Use

  • Select Exam: Choose from available exams on the main screen
  • Answer Questions: Click on any option to select your answer
  • Instant Feedback: Get immediate feedback on whether your answer is correct or incorrect
  • Search: Use the search bar to find specific questions by keyword
  • Print: Use the print button to generate a printable version of the exam
  • Answer Key: Check the answer key section at the bottom for all correct answers

📋 Features

  • 50 carefully crafted multiple-choice questions
  • Organized into 3 sections based on importance
  • Real-time answer validation with visual feedback
  • Search functionality for quick question lookup
  • Print-friendly layout for offline study
  • Responsive design for mobile and desktop
  • Persian language support with RTL layout

📊 Question Sections

  • Section A (Red): Very important and exam-critical questions (Questions 1-30)
  • Section B (Yellow): Important questions (Questions 31-40)
  • Section C (Green): Final review questions (Questions 41-50)

💡 Study Tips

  • Start with Section A questions as they are most likely to appear on exams
  • Use the search feature to focus on specific topics you want to review
  • Check the answer key after completing each section
  • Print the exam for offline practice and annotation
  • Review incorrect answers to understand your knowledge gaps

⚙️ Technical Features

  • Built with vanilla JavaScript for optimal performance
  • Responsive design with mobile-first approach
  • Accessible with keyboard navigation support
  • Print-optimized styles for paper-based study
  • Dynamic question rendering with shuffled options
