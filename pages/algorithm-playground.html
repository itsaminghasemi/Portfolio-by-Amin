🧮 Algorithm Playground - Guide

🌟 About This Project

The Algorithm Playground is an interactive environment for testing and exploring JavaScript algorithms. It allows you to experiment with different algorithms without writing any code.

🎯 How to Use

  • Select Algorithm: Choose an algorithm from the dropdown menu
  • Enter Input: Type your test case in the input field using JavaScript syntax
  • Run: Click the "Run Algorithm" button to execute
  • View Results: See the output displayed in the output panel

📝 Input Format Examples

  • Binary Search: [1, 2, 3, 4, 5], 3 (sorted array, target)
  • Bubble Sort: [5, 2, 8, 1, 9] (array of numbers)
  • Fibonacci: 10 (number of elements)
  • Palindrome: "A man, a plan, a canal: Panama" (string)
  • Linear Search: [10, 25, 30, 45, 50], 30 (array, target)
  • Selection Sort: [64, 25, 12, 22, 11] (array of numbers)
  • Reverse String: "Hello World" (string to reverse)
  • Factorial: 5 (non-negative integer)
  • Prime Checker: 17 (integer to check)
  • Find Maximum: [3, 7, 2, 9, 1, 5] (array of numbers)

⚠️ Error Handling

If an error occurs, it will be displayed in red in the output panel. Common errors include:

  • Invalid JavaScript syntax in input
  • Missing or incompatible arguments
  • Algorithm-specific constraints (e.g., unsorted array for binary search)

➕ Adding New Algorithms

To add a new algorithm:

  1. Create a new .js file in the /algorithms folder
  2. Export your function with a clear name
  3. Add an entry to the algorithm registry
